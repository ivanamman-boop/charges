Дообъезд станций на Яндекс.Картах

Места, где у модели подозрительно мало станций. Оранжевые — кандидаты модели, их проверить первыми: если там найдутся станции, рекомендация может уйти.

Как собрать — Chrome или Edge (Windows)
  1. Открыть Яндекс.Карты, нажать F12 → вкладка Network (Сеть). Включить Preserve log, в фильтре можно оставить All.
  2. Нажать ссылку места ниже — откроется поиск «Электрозаправки» вокруг точки. Медленно подвигать карту по кругу примерно на 2 км в каждую сторону, чтобы список слева обновлялся. Если Яндекс просит уточнить поиск — приблизить.
  3. Поставить галочку и открыть следующее место в той же вкладке, журнал копится.
  4. Каждые 3–4 места сохранять файл: правой кнопкой по списку запросов → Save all as HAR with content → gaps1.har, gaps2.har… Chrome со временем выбрасывает содержимое старых ответов, поэтому чаще, чем в Safari. После сохранения журнал можно очистить (значок ⊘).
  5. Прислать файлы (флешка, облако, Telegram) — импорт, пересчёт и проверку сделаю сам.

На Mac в Safari: Настройки → Дополнения → «Меню Разработка», затем Разработка → Веб-инспектор → Сеть → «Сохранять журнал», экспорт HAR каждые 6–8 мест.
