# 4. Функциональные требования

Методика. Требование записано от лица системы в форме «Система делает ...», одно действие на строку. У каждого указан модуль кода, где оно выполняется, статус и приоритет. Номера модулей М1-М8 совпадают со спецификацией модели. Правила расчёта вынесены в документ 10 (BR).
