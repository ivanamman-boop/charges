# 7. Сценарий расчёта паспорта

Методика. Сценарий описывает, что делает система после выбора точки, в порядке выполнения. Для каждого шага указаны функции кода. Предварительный паспорт (шаги 1-4) показывается сразу, полный (шаги 5-9) дописывает его позже. Версия кода — рабочая копия после 1535f19, 29.10.2026 (ответы РСЗС, 4 ТУ, реестр atomen.ru; зоны и портфель не пересчитаны), репозиторий github.com/ivanamman-boop/charges, сайт ivanamman-boop.github.io/charges и cm641193.tw1.ru. Документ сверен с кодом 29.10.2026.

| Шаг | Что происходит | Где в коде | Время |
|---|---|---|---|
| 1 | При загрузке и при смене условий сайт берёт или считает равновесие всей сети без кандидата для выбранных года, сезона, типа дня и сценария | app.js getBaseline, recomputeFullEquilibrium, equilibrium.js | Секунды, результат кэшируется |
| 2 | Нажатие на карту. Проверка кластера станций, кандидата, зоны и границы МКАД, карточка с прогнозом | app.js onMapClick, refreshPopup, mapview.js zoneAtPixel, portfolioPickAtPixel | Мгновенно |
| 3 | Переход в паспорт (#passport/site/..., zone/..., pt/...). Для зоны и площадки берутся готовые сессии, класс и экономика из zones.json | app.js route, subjectFromRoute | Мгновенно |
| 4 | Предварительный паспорт: прогноз по годам, загрузка, пороги окупаемости, вердикт, «Почему здесь». Для произвольной точки — адрес через Nominatim | app.js buildPassportVm, passport.js renderPassport | Сразу |
| 5 | Локальное равновесие со станцией DC150-2 в текущих условиях: профиль по часам, соседи, потери станций РСЗС | equilibrium.js localEquilibrium, app.js liveFromLocal | Доли секунды |
| 6 | Класс подключения и свободная мощность, затем перебор шести конфигураций, по 12 локальных равновесий на каждую (2026, 2028, 2030 × сезон × день) | grid.js gridClass, equipment.js evaluateCandidateAsync | Около 5 секунд на тёплом кэше |
| 7 | Экономика стандарта DC150-2: CAPEX диапазоном, помесячный поток, окупаемость диапазоном, NPV, при включённом МФППиП — три платежа компенсации | econ-view.js siteEconomics | Мгновенно |
| 8 | Устойчивость вывода: цена энергии и отклонение спроса при NPV = 0, NPV при классе Б. При каком спросе точка окупится за 8 лет — при дорогом и дешёвом подключении (BR-25) | econ-view.js robustness, paybackDemand | Мгновенно |
| 9 | Паспорт перерисовывается полностью: резюме в шапке, блок «При каком спросе точка окупится», таблица по годам, профиль по часам, соседи, варианты оборудования, технические детали | passport.js renderPassport | После шага 8 |
