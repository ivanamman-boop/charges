# 5. Нефункциональные требования

Методика. Требование сгруппировано по атрибуту качества, к каждому записан измеримый порог и способ проверки. Пороги по скорости взяты из спецификации модели, раздел 12.3. Версия кода — рабочая копия после 1535f19, 29.10.2026 (ответы РСЗС, 4 ТУ, реестр atomen.ru; зоны и портфель не пересчитаны), репозиторий github.com/ivanamman-boop/charges, сайт ivanamman-boop.github.io/charges и cm641193.tw1.ru. Документ сверен с кодом 29.10.2026.

| ID | Атрибут | Требование | Как проверяется | Статус |
|---|---|---|---|---|
| NFR-01 | Доступ | Публичная ссылка без регистрации, работа в браузере компьютера и телефона | Открыть с телефона и в режиме инкогнито, ширина 390 px без горизонтальной прокрутки | Выполнено, проверено в Chrome 24.10 |
| NFR-02 | Стоимость и зависимость | Без сервера и платных сервисов. Статический сайт, тайлы OSM без ключей | Нет обращений к закрытым API | Выполнено. Обратное геокодирование произвольной точки идёт в открытый Nominatim (OSM) |
| NFR-03 | Скорость | Смена часа на ползунке не дольше 100 мс | Замер в браузере | Не измерено. Перерисовка идёт без пересчёта сети |
| NFR-04 | Скорость | Паспорт одной точки с подбором оборудования не дольше 5 секунд | Замер на тёплом и холодном кэше | Частично. Предварительный паспорт из расчёта зон — сразу, полный — около 5 секунд на тёплом кэше. На холодном дольше, Web Worker не сделан |
| NFR-05 | Прозрачность | У каждого параметра есть значение, тип (И, Р, Д) и источник | Проверка params.json | Выполнено в данных. У t0_min, eta_ch и f_acq источник не указан. Цена энергии 7,54 ₽ — со слов экспертов РСЗС (наценка 150%), диапазон 7,5–10 ₽ |
| NFR-06 | Воспроизводимость | Данные пересобираются скриптами, расчёт проверяется тестами в Node | npm test и цепочка npm run из README | Выполнено |
| NFR-07 | Сопровождаемость | Расчётные функции не обращаются к странице, их можно запускать в Node и в Web Worker | Код модулей М1-М7 и econ-view.js | Выполнено |
| NFR-08 | Понятность | Тексты сайта понятны читателю без профильного образования | Тест на людях вне команды | Тексты переписаны 26.09 и 21.10, протокол теста нужно приложить |
| NFR-09 | Честность вывода | Сайт явно пишет, что обе стратегии проверены одной моделью, что места городских станций и резерв подстанций — оценки | Проверка текстов «Сравнения», «Методики» и паспорта | Выполнено. Плашки «оценка» у свободной мощности, «нет данных» и «запрошено» у слоёв без данных |
| NFR-10 | Соответствие отчёту | Цифры и допущения сайта совпадают с отчётом и презентацией | Сверка по документу 10, раздел «Сверка с презентацией» | Выполнено по допущениям; слайды с результатами модели нужно обновить по сайту |
