# 1. Роли пользователей

Методика. Для каждой роли записано, кто это, какое решение он принимает и что для этого берёт из системы. Роли выведены из интервью с РСЗС и процесса AS-IS, где решение о площадке принимают до заявки на подключение. Версия кода 0ed6276 от 28.10.2026, репозиторий github.com/ivanamman-boop/charges, сайт ivanamman-boop.github.io/charges и cm641193.tw1.ru. Документ сверен с кодом 28.10.2026.

| Роль | Кто это | Какое решение принимает | Что берёт из системы | Где в системе |
|---|---|---|---|---|
| Аналитик развития сети | Сотрудник РСЗС, готовит адреса и заявки на подключение. Основной пользователь | Какие адреса передать на заявку и с какой станцией | Карта зон, паспорт точки, переток с соседних станций, класс подключения, окупаемость | «Карта зон», «Паспорт», «Сравнение» |
| Руководитель направления | Утверждает волну строительства | Строить в первую очередь, во вторую, отложить или не строить | Статусы зон и кандидатов, сравнение с традиционным подходом, окупаемость и NPV | «Карта зон», «Сравнение», вердикт паспорта |
| Специалист по присоединению | Готовит запрос в сетевую компанию | Подавать ли заявку и на какую мощность | Класс подключения, ближайший центр питания, диапазон цены и срока ТП, данные для заявки | Блок паспорта «Подключение к сети», кнопка «Скопировать для заявки» |
| Внешний наблюдатель | Жюри, партнёр, город | Доверять ли модели | Логика расчёта, источники данных, допущения, результат тестов | «Методика»: словарь, «Откуда данные», «Проверка модели» |
| Разработчик модели | Ведёт код и данные | Какие данные и параметры обновить | Скрипты сборки данных, параметры, автотесты, расчёт зон | Репозиторий, params.json, npm test, npm run compute:zones |
