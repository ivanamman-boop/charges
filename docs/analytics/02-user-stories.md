# 2. Пользовательские истории

Методика. История записана в форме «Как [роль], я хочу [действие], чтобы [ценность]». Критерии приёмки записаны в форме «Дано [состояние] — Когда [действие] — Тогда [результат]», по ним историю можно принять или вернуть. У каждой истории указана корневая причина из ДКП, которую она закрывает, статус по коду и приоритет для бэклога. Версия кода 0ed6276 от 28.10.2026, репозиторий github.com/ivanamman-boop/charges, сайт ivanamman-boop.github.io/charges и cm641193.tw1.ru. Документ сверен с кодом 28.10.2026.
