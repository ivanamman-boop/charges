## Пробелы

- По КП4 нет теста, который проверяет сами цены подключения. Т7 проверяет только формулу окупаемости. С 29.10 цена класса А взята из 4 реальных ТУ РСЗС (BR-29); с актами РСЗС её нужно сверить на большем числе подключений в пилоте.
- По КП2 точность прогноза пока не проверена ни одним тестом. Т1-Т6 проверяют корректность расчёта, а не совпадение с фактом. Это сделает Т11.
- Пороги и статусы карты зон (BR-01 - BR-05) и компенсацию МФППиП (BR-09) проверяет только сверка с презентацией, отдельного автотеста нет.
