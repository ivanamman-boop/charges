# Дыры в данных станций: что дообъехать на Яндекс.Картах

Проверка 24.10.2026: плотно застроенные ячейки 1 км (жильё + офисы выше 0,6), в квадрате ~2 км вокруг которых нет ни одной станции, быстрой или медленной. Скорее всего там не прошёл объезд Яндекс.Карт. Модель видит в такой дыре спрос без конкурентов и поднимает место вверх (так уже было с Коммунаркой 23.09 и югом 26.09).

Как дообъехать: открыть ссылку в Safari с DevTools (Network), пройти карту вокруг точки, сохранить HAR, затем `npm run import:yandex -- файл.har`, `npm run merge:yandex`, `npm run clip:mkad`, `npm run add:planned`, `npm run assign:addresses`, `npm run calibrate:d0`, `npm run reference:equilibria`, `npm run compute:portfolio`, `npm run compute:zones`. Порядок — README.
