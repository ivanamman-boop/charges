# Дыры в данных станций

Обновлено 28.10.2026, после дообъезда 25.10 (9 HAR-файлов) и реестра Дептранса (data.mos.ru, набор 2985). Реестр подтвердил 97% городских быстрых станций, большая часть дыр закрыта. Ниже — что осталось: плотно застроенные ячейки 1 км, где ближайшая известная станция (быстрая или медленная, включая полосу 3 км за МКАДом) дальше 1 км или в радиусе 1,5 км их не больше одной. Часть таких мест — настоящие «пустые» районы (Крылатское, Строгино после проверки 25.10), а не ошибка сбора.

Как дообъехать: чеклист tools/gaps-sweep.html (Chrome: F12 → Network → Preserve log → Save all as HAR каждые 3–4 места), затем `npm run import:yandex -- файл.har`, `npm run fetch:stations`, `npm run merge:yandex`, `npm run merge:city`, `npm run clip:mkad`, `npm run add:planned`, `npm run assign:addresses`, `npm run calibrate:d0`, `npm run reference:equilibria`, `npm run compute:portfolio`, `npm run compute:zones`.
